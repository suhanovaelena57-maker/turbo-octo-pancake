# Лапки и Пена - студия груминга

Одностраничный сайт груминг-студии для собак и кошек.

## Что внутри

- Главный экран с призывом к записи
- Услуги студии
- Прайс с вкладками (собаки, кошки, дополнительно)
- Отзывы хозяев
- Форма онлайн-записи с валидацией

## Технологии

- Чистый HTML, CSS и JavaScript (без сборки)
- Изображения сгенерированы нейросетью
- Адаптивная вёрстка (десктоп и мобильные)

## Запуск

Откройте index.html в браузере или запустите локальный сервер:

```
python -m http.server 8000
```
